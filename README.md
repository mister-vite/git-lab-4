Що робить функція

normalize\_ua\_phone(raw) приводить український телефонний номер до єдиного формату +380XXXXXXXXX.

Вхід: рядок із номером. Допустимі три початки: 0XX..., 380XX... та +380XX.... Після початку має йти рівно 9 цифр номера. Пробіли та дефіси всередині рядка ігноруються.

Вихід: рядок у форматі +380XXXXXXXXX.

Відмова: якщо номер не підходить під правило (занадто короткий або довгий, містить літери чи інші символи, має невідомий початок, порожній, або передано не рядок), функція кидає виняток InvalidPhoneError. Це єдиний тип відмови в усіх випадках.

Як запустити

Встановлення залежностей:

pip install -r requirements.txt

Запуск тестів:

pytest -v



Покриття

Команда для вимірювання покриття:

pytest --cov=phone\_normalizer --cov-report=term-missing

Фактичний результат: 16 тестів пройдено, покриття рядків модуля — 100 % (17 з 17 рядків).

Звіт покриття (вивід терміналу та скріншот) наведено у звіті до практичної роботи.

Що перевіряють тести

Щасливий шлях: усі три допустимі формати дають +380671234567; пробіли та дефіси прибираються.

Відмова: короткий номер, літера в номері, невідомий початок, не рядок і + посередині номера відхиляються через InvalidPhoneError.

Межа: 9 цифр після початку приймаються, 8 і 10 відхиляються.

Додаткові випадки: порожній рядок, рядок лише з роздільників і текст повідомлення про помилку.
